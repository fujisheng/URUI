# 代码约定

URUI 的业务接口保持简洁：HTML/CSS 表达界面，C# 通过 `Document`、`Element` 和显式方法驱动状态。

## C# 和 C++

- 使用四空格缩进与 Allman 花括号。
- 控制语句的主体使用花括号，单行主体也展开。独立语句、字段、局部变量和枚举项逐行书写。初始化器中的各字段单独换行。
- 类型和方法使用 PascalCase，字段和局部变量使用 camelCase。命名空间提供所属模块的上下文，类型名使用 `Document`、`View`、`Stage` 等职责名称。标识符中的 `URUI` 与 `UI` 使用大写。
- 注释放在相关代码上方，优先说明约束、所有权与原因。C# 的 XML 注释标签和正文分行。
- 默认访问级别已经是私有时省略 `private`。通过 `private set`、`private protected` 或 C++ 访问标签表达的访问限制随声明保留。
- 原生内部模块使用 `URUI::RenderPlan` 等命名空间。渲染计划用命名常量表达协议编号与位标志。C ABI 导出、封包字段和外部库接口沿用各自的契约。

## C#

- 特性独占一行。带逻辑的访问器使用完整代码块。
- 公共接口保持窄职责，使用 XML 注释说明参数、所有权、线程和失效条件。
- 样式可使用强类型属性或明确的 Set 方法；Style 读取真实行内覆盖，计算结果与布局分别读取，不伪造 getter。
- 点击注册保留返回的订阅，在 `OnDisable` 中释放；文档重载后重新查询和绑定。
- 每个文件围绕单一职责组织；文件夹与命名空间体现 Documents、Elements、Events、Resources 以及内部子系统边界。
- 较大的 partial 类型按生命周期、资源、录制、提交等职责拆分；初始化状态集中保留，不能因为移动成员改变初始化顺序。
- 业务代码仅依赖 `URUI.Runtime` 的公开接口。

## HTML/CSS

- 为业务需要访问的元素设置清晰、唯一且稳定的 ID。
- 将布局规则写在样式中，显式设置需要的 `display` 与定位方式。
- `Element.Text` 用于普通文字，`SetInnerHtml` 仅用于有意修改结构。
- 用能表达业务含义的 ID 和样式组织界面，让文本及其差异便于人和 AI 阅读。
- 自定义字体填写真实 family，图片路径与 `ImageAsset.Source` 保持一致。

原生指针、渲染资源、桥接令牌和实验实现由内部代码管理。扩展公开 API 时先明确生命周期与失败行为，避免让业务承担内部资源管理。
