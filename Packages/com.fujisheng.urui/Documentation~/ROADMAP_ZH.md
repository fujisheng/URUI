# 路线图

URUI 的方向是让人和 AI 通过文本理解及迭代 Unity UI，由 C# 保持游戏业务边界。当前实现及验证范围见[支持矩阵](LIMITATIONS_ZH.md)，本页后续方向不构成功能或发布日期承诺。

## 当前基础

已提供共享 Surface、多独立 Document、类型化节点与控件、同步输入事件、CSS 样式/动画、资源租约和效果扩展。业务绑定及导航通过独立 FUI.URUI 适配包接入；项目 URP 也已有独立适配实现。Core 自身不依赖 FUI 或 URP 包。URUI.Effect 为可选效果库。

## 后续方向

| 方向 | 后续工作 |
| --- | --- |
| 平台兼容 | 对已构建插件逐项完成 Unity Player/真实设备运行；再评估 Linux、iOS 模拟器等目标 |
| 框架适配 | 继续验证独立适配包的资源、焦点、导航及绑定边界；保持 Core 无业务框架依赖 |
| 渲染管线 | 扩大既有 URP 路径验证，评估其他相机配置、后端与 HDRP |
| 输入与控件 | 真实系统 IME、移动软键盘、设备触摸、手柄与无障碍；评估更多复杂控件 |
| 文档与资源 | 维护使用指南与公开签名的一致性，完善资源诊断 |
| 开发体验 | 评估文本变更预览、热重载与界面调试工具 |
| 质量与性能 | 按游戏 UI 场景、色彩空间和设备建立可复现功能/性能验收 |

完整浏览器和 JavaScript 运行环境不属于当前产品目标。构建、静态审计、Editor 与 Player/设备运行证据分别记录，不相互替代。
