# Borrowed texture checks

Import this folder and `Tests~/Editor/Fixtures/BorrowedImageValidation.cs` plus `Tests~/Editor/Fixtures/Editor/TextureSamplingGpuValidation.cs` into an isolated Unity project that references the current Core package. Run `TextureSamplingGpuValidation.Run` for Gamma and Linear and `BorrowedImageValidation.Run` for ownership/retirement checks; preserve and restore the test project's color-space setting. No Player or performance matrix is run. `URUI.Tests.TextureBorrowing` is a friend test assembly, never a sample/runtime dependency.

Add `--batching` for the three current borrowed-image layouts with batching off/on. The obsolete global RGBA-reference host is removed; native owned-RGBA protocol coverage lives in the standalone contract tests. It reports native texture identity, steady combined groups, recorded DrawMesh submissions and command-buffer bytes. Headless global GPU counters return unusable zero samples, so these are not advertised as driver GPU draw counts.
