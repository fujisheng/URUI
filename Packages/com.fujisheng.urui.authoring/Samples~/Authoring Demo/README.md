# Authoring Demo

Minimal HTML/CSS layout page (`Inventory.html` and `Inventory.css`) designed for quick inspection and editing inside the **URUI Authoring** workbench (`Window → URUI → Editor`).

Import via Package Manager (**URUI Authoring → Samples → Authoring Demo → Import**) into `Assets/` and double-click `Inventory.html` to inspect multi-column Flexbox layout, custom classes, hierarchy editing, and stylesheet rule inspection.
